# RPG Combat Kata (Python)

You'll be building an RPG. The rules will be introduced iteration by iteration on slides during the workshop — this repo is just here to get you up and running.

## Setup

Requires Python 3.10+. No dependencies to install.

## Running the tests

```bash
python3 -m unittest
```

You should see a single passing test. Start writing your RPG combat logic in `main.py` and your tests in `test_main.py` (or split into more files as you go).
