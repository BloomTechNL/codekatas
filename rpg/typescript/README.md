# RPG Combat Kata (TypeScript)

You'll be building an RPG. The rules will be introduced iteration by iteration on slides during the workshop — this repo is just here to get you up and running.

## Setup

Requires [pnpm](https://pnpm.io/installation).

```bash
pnpm install
```

## Running the tests

```bash
pnpm test
```

You should see a single passing test. Start writing your RPG combat logic in `src/main.ts` and your tests in `src/main.spec.ts` (or split into more files as you go).
